# v1.1 Design: OSS Launch + Real Prototype

**Date:** 2026-03-07
**Milestone:** v1.1
**Goal:** Make Argus a public, community-ready project with a real agent framework integration.

## Context

v1.0 shipped 8 phases, 37 plans, 4,008 LOC production, 3,224 LOC tests, 160 passing tests. `pip install argus && argus demo` runs a 4-violation security benchmark on a clean machine in under 2 minutes with no API key.

v1.1 closes the credibility gaps (MagicMock audit logger, stale xfail markers, no LICENSE file) and adds the first real integration (LangChain adapter) before going public.

## Implementation Phases

### Phase 9: Test Cleanup + Foundation

**Goal:** Clean test suite, pin dependencies, add LICENSE — unblocks all other work.

**Scope:**
- Remove all 29 stale `xfail` markers (tests already passing as XPASS)
- Pin `pytest-asyncio==0.24.0` exactly (prevent event loop drift in CI)
- Add `-W error::DeprecationWarning` to pytest config
- Create `LICENSE` file (Apache 2.0 full text)

**Rationale:** Stale xfail markers mask regressions. Must be cleaned before CI is meaningful.

### Phase 10: Core Fixes

**Goal:** Replace the two biggest credibility gaps — MagicMock audit logger and bypassed skill lifecycle.

**Track A — Real AuditLogger Daemon:**
- New `argus/security/audit/daemon.py` with `AuditDaemon` class
- Process model: `subprocess.Popen()` (sync, not fork — fork breaks asyncio)
- Socket path: `trace_dir / "audit.sock"` (scoped per run, no collisions)
- Readiness: `wait_for_socket_ready()` using `socket.connect()` probe (not file existence — races in CI)
- Cleanup: `finally` block → `proc.terminate()` → `proc.wait(timeout=2)` → `proc.kill()`
- Fail-closed: daemon crash raises `AuditUnavailableError`, run halts
- Remove `MagicMock(spec=AuditLogger)` from `argus/cli/run.py` and `demo.py`

**Track B — SkillLifecycleManager Integration:**
- Wire builtin skills (credential_scanner, owasp_top10, security_audit) through existing 7-stage lifecycle
- Skills pass through Install → Verify → Sandbox → Execute → Monitor → Report → Revoke
- Each transition logged in execution trace
- Removes the documented gap where builtins bypass lifecycle

### Phase 11: New Capabilities

**Goal:** First real agent framework integration and containerized deployment.

**Track A — LangChain Adapter:**
- New `argus/adapters/langchain.py` module
- Pattern: proxy/wrapper around `AgentExecutor.invoke()` (NOT callback subclass)
- Why not callbacks: LangChain v1 backgrounds `BaseCallbackHandler` — security violations are caught silently, never propagate. The proxy pattern intercepts synchronously.
- Hook: `gateway.pre_tool_call()` before execution, `gateway.post_tool_call()` on output
- Security violations raise exceptions (fail-closed), never silently swallowed
- Factory: `build_argus_gateway()` with optional daemon wiring
- Optional dependency: `pip install argus[langchain]` — `langchain-core>=1.2.5` (post-CVE-2025-68664)
- LangChain NOT in core deps (avoids 200MB transitive dependency inflation)

**Track B — Docker Deployment:**
- Multi-stage Dockerfile: builder (`python:3.12-slim` + `uv`) → runtime (non-root `argus` user)
- NOT Alpine: musl breaks crypto/pydantic-core/aiosqlite C extension wheels
- `ENTRYPOINT ["argus"]`, `CMD ["demo"]` — enables `docker run argus run --task "..."`
- Socket path: `/tmp/` (never volume-mounted path — macOS Docker Desktop can't connect to sockets in mounted volumes)
- `docker-compose.yml` with `ANTHROPIC_API_KEY` from `.env`
- `.dockerignore`: exclude `.venv/`, `__pycache__/`, `tests/`, `.planning/`
- Rich output: gate on `sys.stdout.isatty()` or respect `NO_COLOR` env var (no ANSI codes in Docker logs)

### Phase 12: OSS Launch Infrastructure

**Goal:** Community-ready repository with CI, contribution guidelines, and security reporting.

**GitHub Actions CI (`.github/workflows/ci.yml`):**
- Jobs: `test` (pytest matrix 3.12 + 3.13), `lint` (ruff check + format), optional `security` (bandit medium+)
- Separate `test-integration` job (main branch only, requires `ANTHROPIC_API_KEY` secret)
- Cache: `astral-sh/setup-uv@v6` with `--enable-cache` (2-5x faster than setup-python)
- Runner: `ubuntu-latest` only (Unix sockets require POSIX)

**Community Files:**
- `CONTRIBUTING.md` — dev setup (uv), running tests, PR process, code style (ruff)
- `SECURITY.md` — private vulnerability reporting via GitHub Security Advisories
- `CODE_OF_CONDUCT.md` — Contributor Covenant 2.1
- `.github/ISSUE_TEMPLATE/bug_report.yml` — structured bug reports
- `.github/ISSUE_TEMPLATE/feature_request.yml` — structured feature requests
- `.github/pull_request_template.md` — PR checklist

**Launch Prep:**
- `CHANGELOG.md` (keep-a-changelog format, seeded with v1.0 + v1.1)
- README badges (CI status, license, Python version, PyPI)
- Enable GitHub Private Vulnerability Reporting before repo goes public

## Key Technical Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Daemon process model | `subprocess.Popen()` sync | Fork semantics break asyncio event loops |
| Socket readiness check | `socket.connect()` probe | File existence races on cold CI runners |
| LangChain integration pattern | `wrap_tool_call()` proxy | Callbacks are backgrounded, security violations swallowed silently |
| LangChain dependency scope | Optional extra only | Prevents 200MB transitive deps in core `pip install argus` |
| Docker base image | `python:3.12-slim` | Alpine musl breaks crypto/pydantic-core/aiosqlite wheels |
| CI runner OS | `ubuntu-latest` only | Unix sockets require POSIX; no Windows/macOS needed |
| CI Python matrix | 3.12 + 3.13 | Minimum supported + forward compat |
| CI dependency tool | `astral-sh/setup-uv@v6` | 2-5x faster than setup-python pip |

## Launch Gate (non-negotiable)

All must be true before the repo goes public:

- [ ] CI green 3 consecutive runs
- [ ] All 29 stale xfail markers removed
- [ ] LICENSE file present (Apache 2.0)
- [ ] SECURITY.md present with private reporting instructions
- [ ] `argus demo` works on clean machine, no API key, no Docker
- [ ] `docker run argus demo` works
- [ ] No ANSI escape codes in Docker log output
- [ ] SkillLifecycleManager wired for builtins (or documented limitation)
- [ ] LangChain adapter example in README or docs/

## Anti-Patterns to Avoid

- LangChain as core dependency (use optional extra)
- `BaseCallbackHandler` for security hooks (use proxy pattern)
- Alpine Linux Docker image (use python:3.12-slim)
- Async subprocess management (use sync Popen)
- Fixed socket paths (use per-run scoped paths)
- `force_terminal=True` without tty check (breaks Docker logs)
- `xfail(strict=False)` on passing tests (masks regressions)
