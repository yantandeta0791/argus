    load_gateway_config(raw: dict) -> GatewayConfig:

    - Calls load_secrets_config(raw) — result.patterns goes to GatewayConfig.prompt_shield_patterns
    - Calls load_egress_config(raw) — result goes to GatewayConfig.egress_allowlist
    - Calls load_hitl_config(raw) — result goes to GatewayConfig.hitl (None when not configured)
    - raw={} returns GatewayConfig() with all defaults — no exception raised
    - ConfigValidationError from any section loader propagates unchanged (not re-wrapped)
    - GatewayConfig is imported lazily inside the function body to avoid circular imports
    - load_spend_profiles is NOT called here — spend config is not a GatewayConfig field
  </behavior>
  <action>
    Add to argus/llm/config.py, after the load_spend_profiles function:

    ```python
    def load_gateway_config(raw: dict):
        """Assemble a GatewayConfig from a raw yaml.safe_load dict.

        Calls all section loaders and returns a fully populated GatewayConfig.
        Raises ConfigValidationError on any invalid policy rule.
        Lazy-imports GatewayConfig to avoid circular imports between argus.llm and argus.security.
        """
        from argus.security.gateway import GatewayConfig

        permissions = load_rbac_config(raw)
        secrets = load_secrets_config(raw)
        egress = load_egress_config(raw)
        hitl = load_hitl_config(raw)

        return GatewayConfig(
            permissions=permissions,
            prompt_shield_patterns=secrets.patterns,
            egress_allowlist=egress,
            hitl=hitl,
        )
    ```

    The section loaders (from Plan 02) handle all validation — load_gateway_config just orchestrates.
